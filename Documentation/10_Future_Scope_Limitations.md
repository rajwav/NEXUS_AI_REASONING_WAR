# 10. FUTURE SCOPE & LIMITATIONS

## 1. Current Limitations
1. **Grid Resolution**: Spatial maps operate on discrete $26 \times 15$ tile grids rather than continuous physics colliders.
2. **Deterministic Opponents**: Adversarial training bots evaluate fixed lookahead depths rather than Deep Q-Networks (DQN).
3. **Local Machine Execution**: Multi-player network synchronization is not included in the single-player research facility scope.

---

## 2. Future Scope & Roadmap
1. **Reinforcement Learning Arena**: Integrate Proximal Policy Optimization (PPO) and Deep Q-Networks (DQN) for real-time robotic combat agents.
2. **Natural Language Dialogue via LLM Embeddings**: Equip NOVA with localized on-device Large Language Models (e.g. quantized Gemma/Llama) for open-ended conversation and custom hint synthesis.
3. **Procedural Mission Generation**: Dynamically generate non-linear facility layouts and randomized CSP constraints using generative grammar models.
4. **VR / 3D Spatial Canvas**: Port the 2D grid engine to an interactive 3D WebGL / Unity environment with isometric camera projection.
